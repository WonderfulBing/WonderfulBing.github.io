## 1. 这部分到底学什么

### 1.1 从“认识功能”走向“读懂文本”

第一部分建立了整体认识，第二部分补充了物理量和单位。

现在需要解决：

> 给我一个真实输入文件，我如何知道每行在做什么、每个数字引用了谁，以及哪些改动会破坏结构？

例如：

```text
10 1 -1.0 -101 imp:p=1
```

你会逐步读成：

```text
栅元 10 → 引用材料 1 → 质量密度 1.0 g/cm³
        → 几何由曲面 101 的指定一侧定义
        → 光子重要性为 1
```

这句话仍不能完整确定形状，因为还需要找到曲面 101 的定义。

**读懂文件的关键是顺着引用继续查，而不只翻译当前行。**

### 1.2 本课的完成目标

学完后应能：

1. 找出标题、栅元段、曲面段和数据段。
2. 区分结构空行、普通空格、注释和续行。
3. 把多行组成的一张卡还原为完整条目。
4. 识别栅元号、曲面号、材料号、分布号和 tally 号。
5. 理解数字相同不一定代表同一个对象。
6. 看懂常见数字简写，知道如何展开检查。
7. 识别“按编号引用”和“按输入顺序对应”的区别。
8. 用一个完整例子解释几何、材料、源和统计的关系。
9. 在 AI 修改后，定位应该联动检查的位置。

本课不要求设计复杂几何或掌握全部 tally。那些属于后续课程。

### 1.3 两个最常见的阅读障碍

**障碍一：把每行当成独立命令。**

实际上，一张卡可能跨多行，某些卡还引用其他卡。

**障碍二：只盯着数字，不看上下文。**

数字的意义由“所在段、卡类型、字段位置、引用方式”共同决定。

## 2. 先区分课程文档与实际输入文件

### 2.1 本文件是 Markdown 教程

本文开头有：

```text
# 第 3 部分：读懂输入文件的整体结构
---
title: ...
date: ...
category: mcnp
post: true
description: ...
---
```

这些用于归类和阅读，不是 MCNP 输入语法。

**不要把课程标题、归类字段、Markdown 表格或代码围栏复制到实际输入文件里。**

尤其是：

- Markdown 中的 `#` 可以表示标题。
- MCNP 中的 `#` 在不同位置可能表示补运算或列式输入等。
- Markdown 中的 `---` 可以是分隔线。
- MCNP 不是靠 `---` 划分栅元、曲面和数据段。

相同字符在两种文件里有不同意义。

### 2.2 实际输入通常是纯文本

常见文件名可能是：

```text
model.i
model.inp
model.txt
```

扩展名有助于人管理，但不能代替检查文件内容。

输入文件不应是 Word 富文本文件改一个后缀，也不应包含编辑器插入的排版标签。

### 2.3 从代码块复制时检查什么

真正应复制的是代码围栏内部的输入文本。

例如课程显示：

````text
```text
mode p
nps 100000
```
````

实际输入中只需要：

```text
mode p
nps 100000
```

反引号围栏、语言标签 `text`、代码块外的解释都不属于实际输入。

### 2.4 行号也不是输入的一部分

教程可能使用：

```text
01 | Example title
02 | 1 0 -1 imp:p=1
```

这里的 `01 |` 是讲解标记，不得原样复制。

后面的完整示例会把“可供识读的原始输入”和“单独的行号说明表”分开，减少混淆。

## 3. 总体结构：先找到三段和标题

### 3.1 最常见的入门结构

```text
标题行
栅元卡
栅元卡

曲面卡
曲面卡

数据卡
数据卡
```

逻辑上分成：

```text
标题
  ↓
栅元段：有哪些空间区域？
  ↓ 一个空行
曲面段：区域边界怎样定义？
  ↓ 一个空行
数据段：材料、粒子、源、统计、控制等
```

标题后通常直接进入栅元内容，**不要因为标题看起来像文章标题，就在标题与第一张栅元卡之间加空行。**

### 3.2 为什么栅元先出现，曲面后出现

输入文件的排列顺序不等于你思考模型的自然顺序。

建模时，你可能先画球面，再定义球内区域；但常见输入结构先写栅元段，再写曲面段。

栅元可以引用稍后在曲面段定义的曲面。因此，一开始读到某个曲面编号还不知道形状，是正常现象。

### 3.3 数据段不是只有材料

数据段常见内容：

| 功能 | 常见卡或关键字 |
|---|---|
| 粒子种类 | `MODE` |
| 材料组成 | `M1`、`M2` 等 |
| 关联热散射数据 | `MT1` 等 |
| 源定义 | `SDEF` |
| 源分布 | `SI1`、`SP1`、`DS1` 等 |
| 统计 | `F4:P`、`F14:P` 等 |
| 统计分组或修饰 | `E4`、`T4`、`FM4`、`DE4`、`DF4` 等 |
| 栅元参数表 | `IMP:P`、`VOL` 等，具体功能与放置规则需核对 |
| 物理与截断 | `PHYS`、`CUT` 等 |
| 运行控制 | `NPS` 等 |
| 变换与重复结构支持 | `TR` 等，配合其他设置 |

这里只是识别地图，不是建议把这些卡全部写进每一个模型。

### 3.4 可选的消息块

有些文件会在标题之前包含 `MESSAGE:` 消息块。

结构示意：

```text
MESSAGE: 执行选项
其他相关执行选项

模型标题
栅元段

曲面段

数据段
```

其中消息块是可选的，具体内容属于执行选项，不是材料或几何。

你不需要主动添加它，但读别人的文件时，要知道这种情况下第一行不一定是问题标题。

上述结构可对照 [MCNP 6.3.1 手册第 3.2.2 节及输入格式图](https://mcnp.lanl.gov/pdf_files/TechReport_2024_LANL_LA-UR-24-24602Rev.1_KuleszaAdamsEtAl.pdf)。

### 3.5 数据段后面的内容

常见新运行文件中，数据段后的空行可以起到终止输入的作用，后面还可能保留不参与当前计算的内容。

因此，数据段内部意外插入空行，可能让后面的材料、源或 tally 不再按你预期生效。

新手更容易检查的安排是：

- 当前输入只保留当前需要的有效内容。
- 备注用合适的注释行。
- 备选模型放独立文件。
- 不依赖“空行后藏着一套备用设置”的组织方式。

## 4. 标题行：给人阅读，但位置有结构意义

### 4.1 标题有什么用

标题帮助人确认当前输入的用途，并在相应输出中识别问题。

例如：

```text
Lesson 03 - water sphere with photon source
```

这个标题有助于说明场景，但它不会自动创建水球和光子源。

真实模型由后面的卡决定。

### 4.2 标题不等于注释卡

没有消息块时，第一行承担标题功能。

不要在标题前先加：

```text
c author and notes
```

然后认为这行必然会像栅元段中的注释一样被跳过。在标题位置，文件读取规则首先要确定标题。

更清楚的方式是：

```text
Lesson 03 - water sphere with photon source
c author and notes
10 1 -1.0 -101 imp:p=1
```

### 4.3 标题宜短而明确

推荐包括：

- 模型主题。
- 重要方案标识。
- 必要的版本或参数标记。

避免只写“test”“new”“final2”而没有任何物理信息。

不同版本对标题存储、显示和输入行长度的细节需要查手册。入门时用一行简短 ASCII 英文标题即可，复杂说明放在后面的注释中。

### 4.4 标题、文件名、注释和实际参数要一致

文件名写 `radius10.i`、标题写 radius 10，而曲面实际写 `so 5`，软件仍按实际曲面计算。

修改模型后也要检查说明，避免人读到的是旧方案、程序计算的是新方案。

## 5. 空行：它是分段符，不是排版装饰

### 5.1 最重要的规则

在本课讨论的普通输入中，空行用于主要功能段之间的分隔。

```text
栅元段结束
【一个空行】
曲面段开始
```

教程中写的 `【一个空行】` 只是说明，真实文件中对应一行没有输入项的空白行。

### 5.2 不能在每个物理对象之间加空行

下面是故意构造的错误示意：

```text
Example title
10 0 -101 imp:p=1

20 0 101 -102 imp:p=1
```

如果这里仍然想继续定义栅元，空行就破坏了原本的段落安排。

软件可能开始把后面的内容按下一个段来读，从而在后续位置报出看起来不直观的错误。

### 5.3 不要用连续多空行美化

普通文章中多一个空行通常只改变视觉间距；在输入中，额外空行可能改变分段或终止位置。

初学阶段，两个主要段之间保留一个空行，更容易核查。

### 5.4 注释行可以组织段内内容

想在数据段中分组，使用注释而不是空行：

```text
c materials
m1 1001 2 8016 1
c source
sdef par=p pos=0 0 0 erg=1
c tally
f4:p 30
c run control
nps 100000
```

这些注释不会像结构空行那样把数据段切开。

### 5.5 文件末尾换行与空白行

这两个容易混淆：

- 最后一行文字结束时有换行符。
- 最后一行文字之后又有一整行空白。

前者只是正常文本行结束，不等于中间多插入一个段分隔空行。

对于本课简单文件，让最后一张卡之后正常结束文件即可；不要求为了排版额外插入多行空白。

### 5.6 看似空行的内容

只有空格或制表符的行，视觉上可能也是空行。不要把“我只打了几个空格”当成可靠的段内分组方法。

使用编辑器的“显示空白字符”功能，能帮助区分普通空格、制表符和真正的行分隔。

### 5.7 最常见的三种空行错误

| 错误 | 可能影响 |
|---|---|
| 标题后立即空行 | 栅元段可能被意外留空或后文错段 |
| 栅元、曲面之间没有空行 | 曲面卡可能仍被当成栅元内容解析 |
| 数据段中途空行 | 后续设置可能不再进入有效数据段 |

不能只根据错误出现的行定位问题，还要向上检查最近的分隔位置。

## 6. 卡、行、字段和关键字

### 6.1 卡 Card 与物理行

一张卡是一个有完整语义的输入条目。

```text
m1 1001 2 8016 1
```

是一张材料卡。

也可以写成：

```text
m1 1001 2
     8016 1
```

这里两行仍然共同构成一张材料卡。

所以：

```text
文件行数 ≠ 卡数量
```

### 6.2 字段 Field

例如：

```text
10 1 -1.0 -101 imp:p=1
```

可以按含义拆成栅元号、材料号、密度、几何、可选参数。

某个字段本身可能由多项组成，例如复杂几何表达式、坐标三元组或数列。

### 6.3 位置式输入

位置式输入依赖字段所在的位置。

例如普通非真空栅元卡中的前几项，不能随意交换顺序。

把材料号与密度交换，不会仅仅改变排版，而会改变或破坏语义。

### 6.4 关键字式输入

例如：

```text
sdef par=p pos=0 0 0 erg=1
```

`PAR`、`POS`、`ERG` 是源定义中的关键字，后面的值由关键字说明。

虽然许多独立关键字组可以采用不同排列，组内的位置仍然有意义：

```text
POS=x y z
```

不能把三个坐标随便排序。

### 6.5 自由字段格式不等于任意格式

在常见水平输入中，字段通常以一个或多个空格分隔，不需要每个数字都对齐到固定列。

但仍然需要满足：

- 新卡起始位置规则。
- 行长限制。
- 完整字段不能随便拆开。
- 段落空行正确。
- 续行方式正确。
- 特殊卡自身的语法。

“自由字段”不能解释成“想加什么标点都可以”。

## 7. 字符、空格、列位置与编码

### 7.1 常见新卡从前五列内开始

在本课对应的常见格式中，新卡的卡名或编号应从前五列内开始。

为了减少歧义，推荐新卡直接从第 1 列开始：

```text
mode p
m1 1001 2 8016 1
```

如果把每一行都缩进五个空格以“代码排版”，可能让本应是新卡的行被当成上一张卡的续行。

### 7.2 行长限制

本课引用的 MCNP 6.2、6.3 系列常见格式说明使用 128 列上限，制表符展开后也要考虑列数。更旧版本可能有更短限制，应查实际版本。

不要依赖编辑器的视觉自动折行判断：

- 自动折行可能只是显示。
- 实际文件里仍可能是一条很长的物理行。
- 真正续行需要在文件中换行并满足输入规则。

保守做法是把长卡按合适边界主动续行，尤其不要让有效参数落在行长上限之后。

### 7.3 用普通空格，少用 Tab

制表符可能被展开到后续制表位，显示列数与实际展开列数可能不同。

为了可检查，建议：

- 新卡不做无意义缩进。
- 续行用明确数量的普通空格。
- 编辑器关闭“用 Tab 替换空格”的自动行为，或保存前检查。

规则可对照 [MCNP 6.3.1 输入格式章节](https://mcnp.lanl.gov/pdf_files/TechReport_2024_LANL_LA-UR-24-24602Rev.1_KuleszaAdamsEtAl.pdf)。

### 7.4 大小写

多数输入助记符不区分大小写，例如常见情况下：

```text
MODE P
mode p
Mode P
```

表示同样的粒子模式。

文件名、路径和外部工具的处理可能另有大小写要求，不能把“助记符不区分大小写”推广到所有字符串。

### 7.5 中文和全角字符

下面这些看起来相似，但不是同一个字符：

| 需要的字符 | 易混淆字符 |
|---|---|
| 半角减号 `-` | 长横线 `—`、数学负号 `−` |
| 半角冒号 `:` | 全角冒号 `：` |
| 半角等号 `=` | 全角等号 `＝` |
| 半角括号 `()` | 全角括号 `（）` |
| 普通空格 | 不间断空格、全角空格 |

在文档解释中使用中文和数学符号没问题，但实际输入字段应使用版本支持的字符。

教程可保留中文解释；正式输入优先采用 ASCII 字符与英文注释，减少编码和解析干扰。

### 7.6 保存与复制检查

还应检查：

- 没有富文本格式。
- 没有行首的 Markdown 引用符号 `>`。
- 没有围栏反引号。
- 没有复制进来的行号。
- 没有不可见前缀干扰标题或卡名。
- 实际文件名与启动时指定的一致。

对普通 ASCII 内容，可使用不含额外前缀的兼容文本保存方式。具体换行与编码支持仍以本机版本为准。

## 8. 注释：给人解释，不改变物理参数

### 8.1 整行注释

最清楚的写法是从第 1 列开始写 `c`，后接空格：

```text
c water region
c photon source at the origin
```

常见格式允许注释标识位于前五列，但初学时无需刻意使用不同缩进。

标题位置与特殊块需要另行识别，不要把一般注释规则无限推广。

### 8.2 行尾注释

```text
101 so 2 $ radius in cm
```

在常见普通卡中，`$` 之后是本行注释，不再作为输入数据解释。

特殊功能块可能存在例外，不能机械套用；例如旧手册对 TMESH 块的相关用法有专门限制，遇到时查对应说明。

### 8.3 注释与有效参数不一致

```text
101 so 2 $ radius is 10 cm
```

实际球半径仍由参数 `2` 决定。

不要只把注释改成目标值却忘记改参数；也不要只改参数，留下误导后续阅读的旧注释。

### 8.4 `$` 不是普通分隔符

下面是故意展示的问题：

```text
mode p $ nps 100000
```

这里 `nps 100000` 位于注释部分，不会成为独立的运行控制卡。

不能用 `$` 把两张有效卡拼到同一行。

### 8.5 注释不能依靠普通续行继续

一般注释卡不要按普通数据卡的方式续行。

长说明可以分成多条完整注释：

```text
c source: isotropic photons
c energy: 1 MeV
c all lengths in cm
```

这样更容易保证内容只是注释，不被误读成其他条目。

### 8.6 注释适合记录哪些信息

- 区域代表的物理对象。
- 尺寸单位。
- 组成和密度的来源或假设。
- 源条件的依据。
- tally 的物理含义。
- 本次修改目的。
- 仍需确认的信息。

解释应当与真实设置相符。不要在未运行时写“运行验证通过”。

## 9. 续行：多行怎样组成一张卡

### 9.1 为什么需要续行

材料可能含多种核素，能量组可能有几十个边界，源定义可能有许多字段。

将这些内容分行，有助于阅读，也能避免超长。

### 9.2 方法一：后续行前五列为空格

```text
m1 1001 2
     8016 1
```

第二行前面有五个普通空格。两行共同表示：

```text
m1 1001 2 8016 1
```

注意第一行并没有结束材料定义，第二行不是独立卡。

### 9.3 方法二：使用行末的 &

```text
m1 1001 2 &
8016 1
```

在本课对应的常见格式中，行末空格加 `&` 表示后续行继续本卡，后续内容不必依靠前五列空白来表达续行。

为了清楚，也可以让下一行仍适当缩进；关键是确认它属于同一张卡。

### 9.4 不要把注释中的 & 当成续行

下面这个写法不能依靠注释中的 `&` 达到续行目的：

```text
m1 1001 2 $ continue &
8016 1
```

`&` 已位于 `$` 注释之后。更稳妥的做法是把续行标志放在有效数据部分的行尾，并将说明另写成完整注释行。

### 9.5 不要拆开一个完整输入项

错误示意：

```text
sdef par=p erg=1.0E-
     3 pos=0 0 0
```

不能依赖续行把 `1.0E-` 与 `3` 重新拼成 `1.0E-3`。

应该在完整字段之间换行：

```text
sdef par=p erg=1.0E-3
     pos=0 0 0
```

同理，不要随意拆开核素标识、文件名或其他完整词项。

### 9.6 一个卡跨多行，不等于行间可以空一行

续行内部不应插入结构空行。

```text
m1 1001 2

     8016 1
```

这不是普通续行排版，而可能提前改变段落或输入终止位置。

### 9.7 两种看起来相近、意义不同的排版

情况 A：

```text
mode p
nps 100000
```

这是两张独立卡。

情况 B：

```text
mode p
     nps 100000
```

在普通续行规则下，第二行可能被拼接到 `MODE` 卡，结果不再是独立的 `NPS` 控制。

所以“把文件整体缩进”是一种需要避免的自动排版操作。

### 9.8 阅读长卡的步骤

1. 找到新卡开始位置。
2. 检查行末是否有续行标志。
3. 检查后续行前五列。
4. 去掉解释性的行尾注释，保留有效字段。
5. 在笔记中还原为一条完整卡。
6. 按卡语法拆解，而不是按屏幕行拆解。

相关续行和注释限制可查 [MCNP 6.2 输入格式与命令摘要](https://mcnp.lanl.gov/pdf_files/TechReport_2017_LANL_LA-UR-17-29981_WernerArmstrongEtAl.pdf)。

## 10. 数字与常见简写

### 10.1 整数、小数和指数

```text
1
1.0
0.001
1.0E-3
```

某些数值位置中，最后两项表示同一个数量。

但编号字段、选项字段和物理量字段有不同限制，不能因为解析器能读一个数，就认定它在任何位置都合法。

部分输入也接受省略 `E` 的指数写法，如 `1.0-3`。初学时主动写 `1.0E-3` 更清楚，看到简写则先确认字段语境。

### 10.2 `nR`：重复前一项 n 次

```text
1 3R 0
```

展开为：

```text
1 1 1 1 0
```

原有的第一个 `1` 仍保留，`3R` 是额外重复三次，不是总共三个 `1`。

例如：

```text
1 2R 0
```

展开为 `1 1 1 0`，共四项。

### 10.3 `nI`：插入 n 个线性插值

```text
0 3I 4
```

展开为：

```text
0 1 2 3 4
```

`3I` 表示两个已给端点之间插入三个数，因此共有五项，间隔数为四。

另一个例子：

```text
1 2I 4
```

展开为 `1 2 3 4`。

### 10.4 `nILOG`：插入对数等距值

```text
0.01 2ILOG 10
```

展开为：

```text
0.01 0.1 1 10
```

相邻值的比例相同，而差值不同。相应端点不能为零，需满足同号等语法条件。

例如不能因为能谱横轴常用对数，就写 `0 10ILOG 1` 并认为有效。

### 10.5 `nM`：前一项乘 n

```text
1 2M 2M 2M
```

展开为：

```text
1 2 4 8
```

`2M` 在这里是简写操作，不是“材料 2”。材料 2 的卡名是 `M2`，位置和顺序都不同。

### 10.6 `nJ`：跳过 n 个位置，使用相应默认值

`J` 常读作 jump。

假设某个位置式参数表要求依次提供四个参数，那么：

```text
10 2J 40
```

意思是：

```text
参数 1=10
参数 2=该位置默认
参数 3=该位置默认
参数 4=40
```

这只是位置概念说明，不是一张可独立运行的卡。

**J 不是数字零，也不是删除该位置。** 默认值是什么、有无默认、该卡是否允许简写，必须查对应卡。

### 10.7 省略次数与组合简写

你可能看到单独的 `R`、`I`、`J`，在支持的语境中通常表示相应一次操作。

也可能看到简写组合。但并不是任意组合都合法，例如前项是跳过的默认占位时，后面的重复操作可能没有合法数值可用。

初学时建议：

- 阅读先展开。
- 修改先展开。
- 检查数量与对应关系之后，再决定是否保留简写。
- 不把简写套到不支持它的卡上。

简写定义可对照 [MCNP 6.2 手册附录 A 输入摘要](https://mcnp.lanl.gov/pdf_files/TechReport_2017_LANL_LA-UR-17-29981_WernerArmstrongEtAl.pdf)。

### 10.8 不能只替换数字字符

例如全局把 `1` 换成 `2`，可能同时改变：

- 材料号 `M1`。
- 能量 `1.0`。
- tally 编号 `14`。
- 曲面号 `101`。
- 科学计数法指数。

真正的修改需要识别字段和引用对象。对输入文件进行无条件全局替换，风险很高。

## 11. 栅元段：区域、材料和参数

### 11.1 普通非真空栅元卡的骨架

为便于讲解，用方括号表示字段占位，实际输入不要复制这些中文占位符：

```text
[栅元号] [材料号] [密度] [几何表达式] [可选参数]
```

例如：

```text
10 1 -1.0 -101 imp:p=1
```

| 内容 | 含义 | 需要继续查什么 |
|---|---|---|
| `10` | 当前栅元的标识号 | 哪些 tally、源或其他设置引用它 |
| `1` | 引用材料 1 | 数据段的 `M1` |
| `-1.0` | 质量密度 1.0 g/cm³ | 是否符合实际条件 |
| `-101` | 采用曲面 101 的负侧 | 曲面段中的 `101` |
| `IMP:P=1` | 光子重要性 1 | 模式及其他区域的重要性 |

不能仅凭 `-101` 就说这个区域是球。只有找到 `101 SO 2` 等定义，才能确定形状。

### 11.2 真空栅元少一个密度字段

普通真空栅元的材料号为零：

```text
20 0 101 -102 imp:p=1
```

这里：

- `20` 是栅元号。
- `0` 表示不填充材料。
- 后面的 `101 -102` 已经是几何条件。

**不要把 `101` 错当成真空密度。**

普通真空栅元不按非真空的格式额外放一个密度项。这也是为什么不能让 AI 用同一个固定字段位置粗暴解释所有栅元行。

### 11.3 几何表达式可能很长

例如：

```text
20 0 101 -102 imp:p=1
```

在同心球例子中，`101 -102` 表示位于内球面正侧、外球面负侧，取两个条件的交。

可能还会遇到：

- 空格：几何交。
- `:`：几何并。
- `#`：几何补。
- `()`：组织组合关系。

这些符号在**栅元几何字段**中有相应含义。它们在别的卡中未必仍然按同样方式解释。

本课先学会找出几何字段的范围，复杂运算在第 5 部分详讲。

### 11.4 `IMP` 不是材料定义

```text
99 0 103 imp:p=0
```

其中：

- 真空来自材料号 `0`。
- 终止光子跟踪来自 `IMP:P=0`。

真空可以允许粒子自由输运；有材料的区域也可以被人为设成重要性零。两类设置各管不同问题。

### 11.5 栅元号可以不连续

例如：

```text
10
20
30
99
```

可以作为四个不同栅元的标识，而不意味着要补齐 1～99 所有整数。

编号之间留间隔，便于后续插入对象。不过合法范围、重复限制和特殊用法仍需按版本与卡类型确认。

### 11.6 一个材料可以用于多个栅元

```text
10 1 -1.0 -101 imp:p=1
40 1 -0.9 201 -202 imp:p=1
```

这两行都引用材料 1，但可以指定不同的区域与密度。这里仅演示字段关系，曲面需要另外定义才能形成模型。

所以：

- 修改 `M1` 的组成，会影响所有引用它的栅元。
- 修改栅元 10 的密度，不会因此自动修改栅元 40 的密度。

### 11.7 普通卡与 `LIKE ... BUT`

如果看到：

```text
20 like 10 but ...
```

这不是“栅元 20 的材料名叫 like”。它属于继承另一栅元属性、再指定差异的特殊写法。

需要先找到被引用的栅元，再叠加 `BUT` 后的变化。原栅元应按相应规则先定义，不能用普通栅元卡的固定字段解释。

本课不提供可直接运行的克隆例子，因为实际还需确保几何、变换和材料等关系正确。参见 [MCNP 6.3.0 手册第 5.2 节 Cell Cards](https://mcnp.lanl.gov/pdf_files/TechReport_2022_LANL_LA-UR-22-30006Rev.1_KuleszaAdamsEtAl.pdf)。

## 12. 曲面段：编号、类型与参数

### 12.1 常见骨架

简单情况下：

```text
[曲面号] [类型] [参数]
```

例如：

```text
101 so 2
```

表示曲面 101，类型为原点球面，半径 2 cm。

### 12.2 几个用于识别的类型

| 示例 | 入门理解 |
|---|---|
| `101 SO 2` | 原点球面，半径 2 cm |
| `201 PX 5` | 平面 x=5 cm |
| `202 PY -3` | 平面 y=-3 cm |
| `203 PZ 10` | 平面 z=10 cm |
| `301 CZ 2` | 以 z 轴为轴线、半径 2 cm 的圆柱面 |

这张表用于识别，不替代第 4 部分的坐标与曲面课程。

例如单独一个 `CZ` 圆柱面并没有自动提供两个端盖。

### 12.3 曲面不是实体材料

```text
101 so 2
```

不会自动生成一个填满水的球。

还要有栅元取它的内部，并引用相应材料与密度。

类似地，一个平面没有厚度；板材通常需要多个边界条件定义空间区域。

### 12.4 曲面卡中的额外数字

有些曲面卡会在曲面号与类型之间出现变换编号等内容。

此时不能简单规定“曲面卡第 2 项永远是类型”。需要识别是否采用了扩展形式，并查对应变换定义。

这是本课反复强调“先识别形式，再按字段解释”的另一个例子。

### 12.5 正负号不是通用的内外口诀

对原点球面，负侧对应球内，正侧对应球外，便于入门。

但对于平面，更合适的说法是满足对应曲面函数的正侧或负侧。例如 `PX 5` 的两侧与 x 相对 5 的大小有关。

不要把所有负号一律翻译成“物体内部”，也不要把坐标参数的负号与几何选择的负号混为一谈。

### 12.6 曲面修改的引用影响

如果多个栅元都引用曲面 101，修改它的半径会同时改变这些区域的共同边界。

这常常是你想要的联动，但也可能改变原本需要保持不动的区域。

修改前应先搜索“曲面 101 在哪些几何字段中被引用”，并避免误把密度、能量等相同数字当成同一引用。

## 13. 数据段：按功能阅读，不按字母猜测

### 13.1 MODE：输运哪些粒子

```text
mode p
```

表示光子模式。

源粒子种类、重要性和 tally 的粒子标识也要与问题匹配。不能只改 `MODE` 就认为整个模型已经完整切换到另一粒子问题。

### 13.2 M：材料组成

```text
m1 1001 2 8016 1
```

表示材料 1 中氢-1与氧-16的原子比例为 2:1。

这里没有写数据库后缀。实际使用需核对默认数据选择及本机可用数据；这行本身也没有声明材料密度。

材料号 `1` 需要与栅元引用对应。

### 13.3 MT：关联热散射处理

遇到 `MT1` 时，应想到材料 1 的相应热散射数据设置，而不是“材料 1 的另一种密度”。

本课的完整光子例子不需要为演示而添加它。中子材料温度与热散射留到后续系统学习。

### 13.4 SDEF：源的关键字集合

```text
sdef par=p pos=0 0 0 erg=1
```

逐项认识：

| 项 | 含义 |
|---|---|
| `PAR=P` | 源粒子为光子 |
| `POS=0 0 0` | 源位置 |
| `ERG=1` | 源能量 1 MeV |

源还可能引用分布，也可能包含方向、空间范围等更多条件。不能仅看有没有 `POS` 就认定它一定是最简单点源。

### 13.5 F：统计主体

```text
f4:p 30
```

表示编号为 4 的光子 F4 类型 tally，统计栅元 30 的相应平均通量。

完整物理单位与归一化请联系第二部分；卡名称里有 flux 不代表默认已经有每秒。

### 13.6 配套卡：统计怎样被修饰

例如：

```text
e4 0.01 0.1 0.5 1.0 2.0
```

为编号 4 的 tally 设置相应能量组。还可能有：

- `T4`：时间分组。
- `FM4`：乘子。
- `DE4`、`DF4`：响应函数相关设置。
- `FC4`：统计注释。
- `SD4`：相关分母或除数设置，可能改变常规归一化解释。

这些卡的精确定义和限制应查手册，不能只读主体 `F4` 就下结论。

### 13.7 NPS：运行控制

```text
nps 100000
```

本课固定源例子设置 100,000 个历史的运行上限。

这不是 100,000 Bq，不是 100,000 秒，也不是 tally 分母之外应再手工除一次的理由。

### 13.8 数据段是否必须固定排列

材料、源、tally 等常见数据卡可以按清楚的功能顺序组织，不要求每份输入都与本课完全相同。

但不能由此推断：

- 任意卡可以搬进任意段。
- 任意高级卡可以不考虑顺序。
- 同一设置可以反复定义并指望最后一条覆盖前面。
- 与位置顺序绑定的参数表可以随意重排。

特殊卡、依赖关系和重复设置应按对应规则判断。

## 14. 编号引用：把文件看成一张关系网

### 14.1 五种编号要分开

| 对象 | 定义位置或方式 | 引用示例 |
|---|---|---|
| 栅元号 | 栅元卡开头 | `F4:P 30` 中的 `30` |
| 曲面号 | 曲面卡开头 | 栅元几何中的 `-101` |
| 材料号 | `M1` 中的 `1` | 栅元材料字段中的 `1` |
| 源分布号 | `SI1`、`SP1` 等的后缀 | `ERG=D1` 中的 `1` |
| tally 号 | `F14:P` 中的 `14` | `E14`、`FM14` 等 |

不同编号体系可以使用相同数字，不能仅凭数字相同就合并理解。

### 14.2 同一个 1 的多种身份

```text
1 1 -1.0 -1 imp:p=1

1 so 2

mode p
m1 1001 2 8016 1
sdef par=p pos=0 0 0 erg=d1
si1 l 0.1 1.0
sp1 0.25 0.75
f4:p 1
nps 100000
```

这个例子仅用来展示编号语境，包含的几何外部还需补全才能作为完整模型。

此处 `1` 可以是栅元号、材料号、曲面号、分布号、重要性值、能量值。

注意 `1001` 是核素标识主体，不是“栅元 1001”或“材料 1001”的自动引用。

### 14.3 定义与引用的关系

```text
栅元 10 的材料字段 1 ───→ M1
栅元 10 的几何 -101 ────→ 曲面 101
F4:P 30 ───────────────→ 栅元 30
E4 ────────────────────→ tally 4
SDEF ERG=D1 ───────────→ 源分布 1
源分布 1 ──────────────→ SI1 / SP1 等相关卡
```

这张关系图比把整份输入逐行翻译成中文更有助于修改。

### 14.4 有定义不代表被用到

例如 `M2` 出现在数据段，但没有任何相关区域或功能使用它，那么它的存在不等于当前模型里已经有一块材料 2。

类似地，一个 `SI2` 被写出来，不代表源一定会从分布 2 抽样；需要追踪引用链。

复杂模型中材料还可能在响应乘子等位置被使用，不能只看栅元材料字段就认定它一定无用。

### 14.5 有引用必须查到合适定义

栅元引用材料 7，文件却只有 `M1`；tally 指向栅元 30，模型中却没有该栅元——这些都需要排查。

在复杂输入中，定义可能来自引用文件、默认数据或其他语法机制。不能只搜不到一行就立刻删除引用；应先查清来源。

### 14.6 编号与文件行号不同

```text
101 so 2
```

`101` 是曲面标识，可能恰好位于文件第 12 行，也可能位于第 500 行。

报错中的“输入行”“卡序号”与模型对象号也要看清，不能混着定位。

## 15. 源分布引用：D1 不是数字 1

### 15.1 常数形式

```text
sdef par=p pos=0 0 0 erg=1
```

这里 `ERG=1` 表示能量固定为 1 MeV。

### 15.2 引用分布

```text
sdef par=p pos=0 0 0 erg=d1
si1 l 0.1 1.0
sp1 0.25 0.75
```

这个简单离散例子中：

- `ERG=D1`：能量从源分布 1 抽样。
- `SI1 L`：列出离散的能量值。
- `SP1`：给出相应概率或相对权重。
- 这里 0.1 MeV 与 1.0 MeV 的选择比例为 25% 和 75%。

本例两组数已经归一化，便于阅读；更复杂 SP 形式包括函数编号、偏置等，不能一律当成普通概率表。

源分布用法可参考 [MCNP6 Source Primer](https://mcnp.lanl.gov/pdf_files/TechReport_2020_LANL_LA-UR-18-21377Rev.1_CurrieRising.pdf)。

### 15.3 必须联动阅读

只看到：

```text
erg=d1
```

还不知道源有哪些能量。必须找到分布 1 的相关卡，识别它采用离散、直方图还是其他形式。

不要把所有 SI/SP 都按本节的离散能线例子解释。

### 15.4 D1 不等于材料 M1

它们只是恰好编号都为 1：

```text
M1 → 材料 1
D1 → 分布 1 的引用
SI1/SP1 → 分布 1 的相关定义
```

### 15.5 更复杂的源要追到引用链末端

可能出现某个源变量依赖另一个变量的分布，或分布再引用其他分布。

此时应画出依赖关系，而不是只找第一对 SI/SP 就停止。

本课先学会发现“这是一个分布引用”，具体设计在第 7 部分展开。

## 16. Tally 编号与配套卡

### 16.1 最后一位决定常见标准 tally 类型

```text
F4:P 30
F14:P 10
F24:P 20
```

三个 tally 的完整编号分别为 4、14、24，最后一位都为 4，因此属于相应 F4 类型。

`F14` 不是“F1 与 F4 两种统计的组合”。

### 16.2 完整编号用于关联配套卡

```text
f14:p 10
e14 0.01 0.1 0.5 1.0 2.0
fc14 average photon fluence response in cell 10
```

`E14` 与 `FC14` 关联完整编号为 14 的 tally。

不是因为类型最后一位为 4，就给所有配套卡统一写成 `E4`。

### 16.3 一份输入可以有多个 tally

例如：

```text
f4:p 30
f14:p 10
```

可以分别统计两个不同区域。

比较结果时要写清楚 tally 编号及对应区域，不能只说“F4 的结果”，因为可能有多张相同类型卡。

### 16.4 同一张 tally 卡上列多个对象

```text
f4:p 10 20 30
```

在这个常见形式中，列出多个栅元进行相应分组统计。

若出现括号组合，含义可能涉及组合区域和相应平均方式，需查 tally 规则。不要把栅元几何中的括号运算原封不动套到 tally 中。

### 16.5 星号与加号也可能改变含义

例如 `*F4`、`*F8`、`+F6` 不应被当成简单排版符号。

它们可能改变所统计的量、单位或估计方式，不同 tally 的修饰规则并不完全相同。

本课先建立“卡名前的修饰也要读”的习惯。具体物理解释结合第 2、8 部分。

### 16.6 E 卡列出的是什么

在本课的标准能量分组例子中，`E4` 列出相应能量组上界，而不是一串任意采样点或源能量。

```text
e4 0.01 0.1 0.5 1.0 2.0
```

可以按第一组到 0.01 MeV、后续到 0.1、0.5、1.0、2.0 MeV 来识读。实际分组、端点归属与总计行应看输出确认。

普通分组 tally 常给出组积分响应，不要因为组边界有能量单位，就认定结果已按每 MeV 归一化。

### 16.7 `E0` 这类零号形式需要特别识别

某些配套卡支持零号形式作为相应的全局默认设置，再由专用卡覆盖或补充。

因此没有 `E14` 时，不能在尚未检查 `E0` 等全局设置前就认定 tally 14 一定没有能量分组。

不同卡的零号规则并不完全相同，需要查具体说明，不要把“0 代表全局默认”扩展到所有编号。

## 17. 位置对应参数表：最容易读错的关联

### 17.1 两种重要性写法

写法 A：放在每张栅元卡上。

```text
10 1 -1.0 -101 imp:p=1
20 0 101 -102 imp:p=1
30 0 102 -103 imp:p=1
99 0 103 imp:p=0
```

写法 B：从栅元卡中去掉该参数，在数据段按顺序给出。

```text
imp:p 1 1 1 0
```

这里 B 需要配合不含相同内联重要性设置的栅元卡，不能把两套写法不加判断地叠加。

### 17.2 按输入顺序，不按数值下标补空位

假设栅元卡按下面顺序出现：

```text
10
20
30
99
```

那么四项对应：

| 数据表位置 | 对应栅元 | 重要性 |
|---:|---:|---:|
| 1 | 10 | 1 |
| 2 | 20 | 1 |
| 3 | 30 | 1 |
| 4 | 99 | 0 |

这里不是“第 99 项才属于栅元 99”，也不需要插入 98 个占位。

### 17.3 简写展开

```text
imp:p 1 2R 0
```

展开为 `1 1 1 0`，与上面四个栅元顺序对应。

### 17.4 重排栅元卡，可能改变对应关系

如果把栅元顺序改成：

```text
99
10
20
30
```

仍保留：

```text
imp:p 1 1 1 0
```

那么重要性零就对应到栅元 30，而不是原来的外部栅元 99。

哪怕所有栅元号都没改，也可能改变实际输运。

### 17.5 一种内联参数不要又写成同名表

在本课采用的普通规则下，已在栅元卡上定义的同类栅元参数，不应再在数据段重复用同名参数表定义。

不能把数据段参数表简单理解为“覆盖前面的内联设置”。具体约束参见 [MCNP 6.3.0 手册栅元参数说明](https://mcnp.lanl.gov/pdf_files/TechReport_2022_LANL_LA-UR-22-30006Rev.1_KuleszaAdamsEtAl.pdf)。

### 17.6 其他位置表也要有映射意识

某些体积、温度、重复结构或其他参数也可能按对应顺序输入，具体取决于卡形式。

不要一律认定“数据段所有数字都是直接写对象编号”。先查该卡是：

- 按显式编号引用。
- 按栅元或曲面输入顺序对应。
- 按另一张卡中的分组顺序对应。
- 由其他依赖关系确定。

### 17.7 最实用的阅读表

遇到位置式参数表，自己展开成：

```text
第几项 → 哪个对象 → 数值 → 单位或意义
```

尤其在 AI 新增、删除或重排栅元之后，应重新检查整张表。

## 18. 完整示例：源在水球中，统计外部真空球壳

### 18.1 模型说明

这个例子用于文件结构识读，不是用于代表你的真实装置。

```text
中心点光子源
    ↓
半径 2 cm 的简化水球
    ↓
2～9 cm 的真空区域
    ↓
9～10 cm 的真空统计球壳
    ↓
10 cm 外终止光子跟踪
```

源在水球内部，水不是围绕真空源腔的空心球壳。

统计球壳是真空，是一个用于统计的空间区域，不是实体探测器材料。

### 18.2 编号安排

| 对象 | 编号 | 含义 |
|---|---:|---|
| 栅元 | 10 | 水球内部 |
| 栅元 | 20 | 中间真空区 |
| 栅元 | 30 | 真空统计球壳 |
| 栅元 | 99 | 外部终止区 |
| 曲面 | 101 | 半径 2 cm 球面 |
| 曲面 | 102 | 半径 9 cm 球面 |
| 曲面 | 103 | 半径 10 cm 球面 |
| 材料 | 1 | 简化水组成 |
| tally | 4 | 球壳内光子 F4 类型统计 |

这里用不同范围的号，帮助初学者区分对象；不是软件强制要求。

### 18.3 完整教学输入

```text
Lesson 03 - photons from the center of a water sphere
c cells
10 1 -1.0 -101 imp:p=1
20 0 101 -102 imp:p=1
30 0 102 -103 imp:p=1
99 0 103 imp:p=0

c surfaces
101 so 2
102 so 9
103 so 10

c data
mode p
c material 1: simplified water, atom ratio H-1:O-16 = 2:1
m1 1001 2 8016 1
c source: isotropic point photons, energy in MeV
sdef par=p pos=0 0 0 erg=1
c tally 4: average photon fluence response in cell 30
f4:p 30
e4 0.01 0.1 0.5 1.0 2.0
nps 100000
```

这里未显式指定数据表后缀。实际运行前应确认本机默认光子数据与相关数据可用、所用版本支持相应输入，并检查实际输出读取记录。

本例不宣称已跑通，也没有提供真实计算结果。

行号用于下面的解释，不属于实际输入。

| 行 | 内容类别 | 阅读重点 |
|---:|---|---|
| 1 | 标题 | 说明模型主题，不生成物理对象 |

| 14 | MODE | 光子输运 |

| 17 | 注释 | 源说明 |

### 18.5 几何条件逐个展开

对于本例的同心球：

```text
栅元 10：r < 2 cm
栅元 20：2 cm < r < 9 cm
栅元 30：9 cm < r < 10 cm
栅元 99：r > 10 cm
```

边界由相应曲面描述，不能把上面的严格不等式理解为程序“遗漏所有边界点”；边界穿越按几何处理规则处理。

在远离边界的代表点，可进行手工归属检查：

| 坐标 cm | 半径 r | 对应区域 |
|---|---:|---|
| `(0,0,0)` | 0 | 栅元 10，源点 |
| `(5,0,0)` | 5 | 栅元 20 |
| `(9.5,0,0)` | 9.5 | 栅元 30 |
| `(11,0,0)` | 11 | 栅元 99 |

这能检查基本理解，但不替代几何可视化和实际运行。

### 18.6 为什么材料卡在后面仍能被引用

栅元 10 中引用材料 1，数据段才定义 `M1`，这是普通模型结构的一部分。

不要为了让材料“先定义后使用”，把 `M1` 搬到栅元段里。

不同机制有不同顺序规则，例如 `LIKE ... BUT` 的继承对象顺序要求，不能用材料卡的情况推断一切引用都可任意向后。

### 18.7 为什么本例不能套用第一课的真空解析值

第一课整个内部是真空，粒子从中心直线穿过球壳。

本例中心区域填入水，光子可能在到达外部球壳前发生相互作用，改变能量、方向或产生相关后续过程。

因此不能把第一课真空值当成本例的必然答案。

如果为了检查流程而把栅元 10 改成真空，就需要同时按真空格式去掉密度字段，避免把原密度当成几何内容。

### 18.8 预期得到什么类别的结果

本例希望得到：

- tally 4 的光子体积平均响应。
- 相应能量组的结果和统计误差。
- 模型与运行的诊断信息。

默认固定源归一化时，结果通常按每个源粒子给出，不直接是实际剂量率或探测器计数率。

由于本例没有提供真实源发射率，不应凭 `NPS=100000` 给结果加上每秒单位。

### 18.9 用一段话解释完整文件

尝试复述：

> 这是一个固定源光子输运模型。原点处有 1 MeV 各向同性点源，源位于半径 2 cm、密度 1 g/cm³ 的简化水球内。水球外到 9 cm 是真空，9～10 cm 是真空统计球壳，超过 10 cm 终止光子跟踪。tally 4 统计球壳中的平均光子响应，并按给定能量上界分组。历史数设置为 100,000，实际运行仍需要核对版本、数据和输出。

如果能自己说出这段意思，说明你已经开始把输入文本还原为物理模型。

## 19. 读一份陌生输入：六轮阅读法

### 19.1 第一轮：确认文件和范围

先确认：

- 当前打开的是输入文件，还是输出回显、课程笔记或后处理文件？
- 是否包含消息块？
- 标题是什么？
- 主要分段在哪里？
- 数据段是否中途意外结束？
- 是否引用外部文件？

第一轮不求理解每个物理参数，先找出“哪些内容真正参与当前输入”。

### 19.2 第二轮：整理对象表

建议做三张基础表。

栅元表：

| 栅元号 | 材料号 | 密度及单位 | 几何引用 | 主要参数 | 暂定物理对象 |
|---|---|---|---|---|---|
| 10 | 1 | 1.0 g/cm³ | -101 | IMP:P=1 | 水球 |

曲面表：

| 曲面号 | 类型 | 参数及单位 | 被哪些区域引用 |
|---|---|---|---|
| 101 | SO | 2 cm | 栅元 10、20 |

材料表：

| 材料号 | 组成 | 份额类型 | 数据说明 | 使用位置 |
|---|---|---|---|---|
| 1 | H-1、O-16 | 原子比例 | 需核对默认数据 | 栅元 10 |

对复杂文件先标注未知项，不要为了完成表格就猜一个解释。

### 19.3 第三轮：还原几何

根据曲面和栅元表，尝试：

- 画简单截面草图。
- 找几个远离边界的代表点判断区域。
- 确认源是否位于预期区域。
- 确认统计区域是否位于预期位置。
- 查找外部终止区域。

遇到变换、填充、重复结构时，要先识别相关坐标系或层级，再画图。

### 19.4 第四轮：完整读取源

按以下顺序说明：

```text
粒子类型
→ 位置与空间分布
→ 方向分布
→ 能量分布
→ 时间或其他依赖
→ 源权重与归一化
```

只看到 `POS=0 0 0` 不代表已经解释完整源。

### 19.5 第五轮：完整读取统计

对每一个 tally 单独写：

```text
完整编号：
类型：
粒子：
对象或位置：
能量分组：
时间分组：
响应乘子及其他修饰：
体积、质量或除数设置：
原始单位：
归一化：
最终用途：
```

如果没有找到某张专用配套卡，仍需检查是否存在相应全局默认设置或其他修饰。

### 19.6 第六轮：核对计算与依赖

最后检查：

- 模式、源、重要性与 tally 是否兼容。
- 历史数和其他结束条件。
- 输运截断与物理选项。
- 数据表和相关外部依赖。
- 位置参数表是否与对象顺序匹配。
- 注释和当前方案是否一致。

完成后再判断“我理解了哪些内容，还有哪些未知项”。

### 19.7 为什么不推荐先逐字翻译

逐字解释可以帮助查局部语法，但容易丢失关联：

- 注释可能是旧的。
- 一张源卡可能只写了分布引用。
- 一张 F 卡可能被其他配套卡改变响应。
- 相同材料号可能关联多个区域。
- 一个参数表可能因重排栅元而错位。

先建立关系图，再逐项检查，会更容易发现这类问题。

## 20. 修改示例：不只改一个看得见的数字

### 20.1 把水球半径从 2 cm 改成 3 cm

直接相关的曲面是：

```text
101 so 2
```

改成：

```text
101 so 3
```

还应检查：

- 水区变大是否符合目的。
- 中间真空区是否应随之缩小。
- 源仍在水区内吗？
- 是否有体积、质量或其他依赖半径的用户输入。
- 注释与方案名是否应更新。

默认可计算的几何体积与用户手动指定的体积或除数是不同情况，不能一概认为软件都会自动修正。

### 20.2 把水球改成真空

原来：

```text
10 1 -1.0 -101 imp:p=1
```

普通真空格式应为：

```text
10 0 -101 imp:p=1
```

需要同时去掉原材料密度字段。

错误示意：

```text
10 0 -1.0 -101 imp:p=1
```

这时 `-1.0` 不会仍被理解为真空密度，而可能进入几何解析，导致错误或意外含义。

之后还需检查 `M1` 是否被其他功能使用；不要未核对就删除所有相关数据。

### 20.3 把材料 1 改为材料 7

如果只是重新编号同一材料，应检查：

- `M1` 的定义改为 `M7`。
- 所有引用材料 1 的相关位置。
- 若有 `MT1` 等关联材料的配套设置。
- 某些统计乘子或其他功能中对该材料的引用。

不要全局把字符 `1` 换成 `7`，因为源能量、曲面号和核素标识等也可能包含 `1`。

### 20.4 把统计球壳移动到 19～20 cm

如果保持厚度 1 cm，应检查并修改：

```text
102 so 19
103 so 20
```

中间真空区随之扩大，外部终止边界也改变。

如果只把外半径改成 20，统计区域变成 9～20 cm，并不是原来的薄球壳整体移动。

### 20.5 把 tally 4 改成 tally 14

原来：

```text
f4:p 30
e4 0.01 0.1 0.5 1.0 2.0
```

应改成相关联的形式：

```text
f14:p 30
e14 0.01 0.1 0.5 1.0 2.0
```

还要检查 `FC4`、`FM4`、`T4`、`DE4`、`DF4`、`SD4` 等是否存在，以及外部后处理是否按编号 4 查找结果。

保留最后一位为 4，才仍属于相应 F4 类型；随意改为 15 会改变 tally 类型。

### 20.6 把单能源改成两个能线

原来：

```text
sdef par=p pos=0 0 0 erg=1
```

一个简单离散方案为：

```text
sdef par=p pos=0 0 0 erg=d1
si1 l 0.1 1.0
sp1 0.25 0.75
```

这是改变源能量分布；`E4` 的统计能量分组不是源能谱定义，不能只修改 `E4` 代替改源。

还应检查真实源发射率是否对应整套混合源，以及响应换算是否仍成立。

### 20.7 改历史数

```text
nps 1000000
```

表示改变计算抽样规模，不表示改变真实源强。

正式比较前后结果时，应考虑各自统计误差，不能把任意数值变化都归因于物理条件改变。

### 20.8 修改后保留一份变化说明

可用如下表格：

| 修改项 | 修改前 | 修改后 | 物理目的 | 联动检查 |
|---|---|---|---|---|
| 外球壳位置 | 9～10 cm | 19～20 cm | 统计更远处场 | 两个球面、体积、边界与输出说明 |

这比只保存一个名为 `final_new2` 的文件更有助于后续核查。

## 21. 常见结构错误与排查方向

### 21.1 先分清错误层次

| 层次 | 典型问题 |
|---|---|
| 文本与格式 | 全角字符、超长行、缩进或续行错误 |
| 分段 | 空行多了、少了或位置不对 |
| 语法与引用 | 缺材料、缺曲面、错编号、字段数量不符 |
| 几何与物理 | 区域错误、源放错、材料不符 |
| 统计与解释 | tally 定义不完整、归一化误读、换算重复 |

“文件语法通过”只能覆盖其中一部分。

### 21.2 报错位置可能不是错误起点

例如栅元段漏了空行，程序可能在本应是曲面卡的位置报错。

真正原因在更早的分段，而不一定是当前曲面参数本身不合法。

建议先看第一条有意义的错误，并向上检查段落边界和最近完整卡。

### 21.3 典型问题表

| 现象 | 优先检查 |
|---|---|
| 卡名似乎不被识别 | 所处段、行首位置、全角字符、是否被续到上一卡 |
| 一行数字被当作新卡 | 原本是否应为续行，前五列与 `&` 是否正确 |
| 某张源卡似乎不起作用 | 是否在数据段有效范围，是否位于 `$` 后或输入终止后 |
| 数据表项数不符 | 简写展开后有几项，是否与对象顺序匹配 |
| 引用不存在 | 是对象号、行号还是参数值，定义是否在外部文件 |
| 材料错误 | 栅元引用与 M 卡号是否一致，数据表是否可用 |
| 某个 tally 缺少预期分组 | 配套卡是否关联完整编号，有无全局默认 |
| 改真空后突然报几何错 | 是否保留了原非真空密度字段 |
| 改善排版后报错 | 是否加了结构空行、整体缩进或拆开完整数字 |

### 21.4 结构错误可能造成连锁报错

一处空行或续行错误，可能导致后面多张卡全部按错误上下文解释。

不要同时“修正”所有看起来异常的参数。先修最早的结构问题，再重新检查。

### 21.5 注释不能证明设置已启用

```text
c source uses two photon energies
sdef par=p pos=0 0 0 erg=1
```

这段有效源仍是单一的 1 MeV 设置，不能因为注释写了两个能量就认定它是双能线源。

### 21.6 不要用删除报错行代替理解

某行卡报错时，直接删除可能让文件进入下一步，但也可能同时删掉重要物理设置。

应当先确认该卡负责什么、为什么报错、是否存在合理替代，以及删除后模型是否仍符合需求。

## 22. 遇到复杂语法时先识别什么

### 22.1 列式输入

有些输入会用以 `#` 开始的列式格式来组织一组参数，而不是每张卡都采用本课的水平写法。

在这里 `#` 不能直接按几何补运算解释。

识别后应查列标题、每列所属参数和行对象，避免把整块当成普通注释或无效文本。

### 22.2 TR 与 TRCL

遇到变换，需要确认：

- 定义的是哪一种变换。
- 谁引用它。
- 几何坐标是局部还是全局。
- 源或 tally 是否也需要采用相应关系。

不能看到 `POS=0 0 0` 就直接断言它与某个被变换几何中心重合。

### 22.3 U、LAT、FILL

这些与宇宙、晶格或填充等重复结构功能有关。

“每个空间点对应一个区域”的初学理解，需要结合所在层级展开；不能把所有不同层级栅元当成同一层的重叠实体。

本课只要求识别这是重复结构内容，具体在后续进阶识读中学习。

### 22.4 READ 或外部输入依赖

某些文件通过相关读取功能引入其他文本。

这时当前主文件可能不包含全部定义，需要追踪外部文件、相对路径和读入位置。格式行为与限制需按版本手册核对。

不要因为主文件短，就认定模型简单；也不要把找不到的定义一律判断为缺失。

### 22.5 继续运行与新运行

继续运行文件可能以不同形式工作，并依赖先前保存的运行状态。

它不一定具备本课展示的完整新运行三段结构。

因此，遇到明显不符合模板的文件，应先确认它是不是继续运行、消息文件、绘图命令文件或其他辅助文件。

### 22.6 特殊块与通用规则的边界

部分网格、源、绘图或其他专门功能采用自己的块结构和限制。

本课的空行、注释和续行规则适合所声明范围内的普通输入；特殊功能应看专门说明，不能按直觉自动重新排版。

### 22.7 如何向 AI 请求解释复杂文件

可复制下面的请求，作为以后学习的工具：

```text
请解释这份 MCNP 输入，先不要修改文件。

请依次给出：
1. 文件类型、可能适用版本、是否包含外部依赖。
2. 标题及主要功能段的位置。
3. 将续行合并后的完整卡列表。
4. 栅元、曲面、材料、源分布、tally 的编号表。
5. 按编号引用与按输入顺序对应的关系。
6. 源定义的全部引用链和重要默认值。
7. 每个 tally 的主体、配套卡、物理量、单位与归一化。
8. 复杂或暂时无法确定的语法，以及需要查手册的地方。
9. 已发现的问题及其依据。

请区分文件中的实际设置、注释中的说法和你的推断。
不要声称已经运行，除非确实提供了相应运行输出。
```

### 24.1 结构题答案

**题 1：**在不使用可选消息块的普通新运行形式中：标题后接栅元段，一个空行分隔到曲面段，再一个空行进入数据段。标题与栅元之间不要为了排版另加分隔空行。

**题 2：**不能随意加。空行有结构意义，可能让栅元段留空或让后续内容按错误的段读取。

**题 3：**它们属于课程文档的归类和排版信息，不是 MCNP 的输入卡语法。实际输入需要按自身结构组织。

**题 4：**不是。存在续行，一张卡可以占多行；也有整行注释和分隔空行。

**题 5：**前五列为空可能表示上一卡续行，于是 `NPS` 内容被接到 `MODE` 卡，不再是独立卡。

**题 6：**不作为独立 NPS 卡生效。它位于 `$` 注释部分。

**题 7：**用完整注释行，例如 `c materials`、`c source`，不要在有效数据段内部为了分组插入结构空行。

**题 8：**不等同。自动折行可能只是视觉显示，实际物理行没有分开；真正续行需满足输入规则。

### 24.2 简写题答案

**题 9：**`2 2 2 2 0`，共五项。`3R` 是额外重复前值三次。

**题 10：**`0 2 4 6 8`。插入三个值，分成四个等间隔。

**题 11：**`0.001 0.01 0.1 1`。相邻值之比为 10。

**题 12：**`1 3 9`。每个 `3M` 将前一数值乘以 3。

**题 13：**不是。表示跳过两个位置，采用相应默认值；默认值是否为零及该卡是否允许，需要查具体规则。

**题 14：**`2M` 在允许简写的数列中是乘法操作；`M2` 是材料 2 的卡名。不能交换解释。

**题 15：**不能。完整数字项应在同一行完成，可以在完整项之后续行。

### 24.3 对象题答案

**题 16：**栅元号 10；材料号 1；质量密度 1.0 g/cm³；几何采用曲面 101 负侧；光子重要性为 1。形状还需查曲面 101。

**题 17：**栅元 20，真空，几何为曲面 101 正侧与 102 负侧的交，光子重要性 1。普通真空栅元不填密度项，这里的 101 属于几何。

**题 18：**不会。它只定义球面，材料由相应栅元引用与密度等设置决定。

**题 19：**不需要，也不应为此搬到错误段。普通结构中材料定义位于数据段，栅元可通过材料号引用。

**题 20：**是栅元编号 30，不是文件行号。

**题 21：**不是。`M1` 是材料 1，`SI1/SP1` 属于分布 1 的相关定义，是不同编号体系。

**题 22：**不能。正负侧应结合曲面函数和类型理解；“负侧在球内”是球面的特定直观情况，不是所有曲面的通用口诀。

### 24.4 关联题答案

**题 23：**`ERG=1` 给定常数能量 1 MeV；`ERG=D1` 引用分布 1，需要继续查看其完整定义。

**题 24：**光子从原点发出，能量按离散分布 7 抽样：0.2 MeV 的比例为 40%，0.8 MeV 为 60%。方向和其他设置还应结合完整源定义及默认规则。

**题 26：**不能。还要检查 `E0` 等相应全局设置及其他相关卡和输出。

**题 29：**不能。应按栅元参数规则避免不允许的重复定义，不能推断“最后写的覆盖前面”。

### 24.5 修改题答案

**题 30：**源在栅元 10 的水球中；统计球壳为栅元 30，真空，没有实体探测器材料。

**题 31：**不够。还应把内半径曲面 102 改为 19 cm。只改外半径会得到 9～20 cm 的厚球壳。

**题 32：**普通真空卡没有原来的密度字段。保留 `-1.0` 可能使它进入几何解析。应将该行改为 `10 0 -101 IMP:P=1`，再核查其他依赖。

**题 33：**查 `E4`、`T4`、`FM4`、`FC4`、`DE4/DF4`、`SD4` 等实际存在的配套卡以及后处理程序。不能只改 F 卡。

**题 34：**不等于。E4 是 tally 的统计分组，源能量由 SDEF 及相关分布决定。

**题 35：**先追踪读取的外部文件、读入位置、相对路径与完整定义来源，再判断是否确实缺失。

**题 36：**不应立即盲改。先看第一条有效错误，向上检查空行、段落与续行，确认是不是结构错误导致后续卡被误读。

### 24.6 找错题答案

**题 37：**`E4` 行被缩进五个空格，可能成为 F4 的续行。若要独立配套卡，应使新卡从前五列内开始，初学时直接从第 1 列写 `e4`。

**题 38：**`&` 位于 `$` 后的注释部分，不起有效续行标志作用；下一行又没有五空格续行。可改为：

```text
m1 1001 2 &
8016 1
```

或：

```text
m1 1001 2
     8016 1
```

**题 39：**不一致。常见 `ERG` 单位为 MeV，`ERG=100` 表示 100 MeV。100 keV 应为 0.1 MeV，需核对需求后修正参数与说明。

**题 40：**还需核对几何、材料、源、数据、统计目标、单位与归一化，检查实际运行和统计表现，并根据应用进行合理性核对与验证。格式正确只是其中一层。

| 为什么一行不生效 | 所在段、注释、续行、输入终止与外部读取 |
| 改号后影响哪里 | 所有定义、引用和外部后处理 |

本课为自行编写的教学讲解，例子用于帮助理解结构，不替代实际版本手册。示例中的水密度和组成属于入门简化，没有提供实际计算或应用验证结果。

### 26.2 推荐的查手册顺序

```text
先查文件整体格式
      ↓
确认当前卡属于哪一类
      ↓
核对语法与允许的位置
      ↓
核对字段、单位、默认值和限制
      ↓
追踪其他被引用的卡
      ↓
结合几何图、实际输出和适当验证检查理解
```

不必为了学会阅读简单文件而先背完整手册。把眼前模型中实际用到的结构和关系查清楚，再逐步扩大掌握范围。
